# 🚀 ATS Resume Analyzer

A modern full-stack ATS (Applicant Tracking System) Resume Analyzer that compares a PDF resume with a job description and provides an ATS match score, matched skills, missing skills, personalized recommendations, and a downloadable PDF report.

---

## 🌐 Live Demo

🔗 https://ats-resume-analyzer-frontend-o5wy.vercel.app

---

## ✨ Features

- 📄 Upload PDF Resume
- 📝 Paste Job Description
- 🎯 ATS Match Score
- 📊 Circular Score Indicator
- 📈 Match Progress Bar
- ✅ Matched Skills Detection
- ❌ Missing Skills Detection
- 💡 Personalized Recommendations
- 📥 Download ATS Analysis Report (PDF)
- 📱 Responsive UI
- ⚡ FastAPI Backend
- ⚛️ React Frontend

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_LINK>
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Backend

```bash
cd backend

python -m venv venv

# Windows
venv\Scripts\activate

# macOS/Linux
source venv/bin/activate

pip install -r requirements.txt

uvicorn main:app --reload
```
